# マダラ取りフィルタ

生成画像に乗る「マダラ状のノイズ」（ザラつき・色ムラ）を測って、輪郭や文字を残したまま色面を滑らかにするブラウザ用ツールです。
画像生成は使わず、従来の画像処理だけで補正します。処理はすべてブラウザ内で行い、画像はどこにも送信されません。

## 使い方

`index.html` をブラウザで開くだけで動きます（サーバー不要）。GitHub Pages で公開すれば、スマホからも使えます。

1. 「画像を選ぶ」、ドラッグ＆ドロップ、貼り付けのどれかで画像を読み込む
2. 自動で測定され、おすすめ設定が適用される
3. 比較線や 2倍・4倍表示で確認しながらパラメータを調整
4. 「PNGで保存」

スマホでは、画像が画面いっぱいに表示され、下のチップ列で項目を選んで1本のスライダーで調整する画面になります。

## 機能

| グループ | 項目 | 内容 |
|---|---|---|
| 分析 | ザラつき / マダラ | 平坦な色面だけで、細かい粒ノイズとにじみ状のムラを数値化（補正前→補正後） |
| 補正 | 平滑化の強さ・くり返し回数 | 輪郭をまたがない平滑化（ガイデッドフィルタ） |
| | 粒ノイズ除去 | 3×3 メディアンで孤立点を除去 |
| | 輪郭・文字の保護 | 線や文字の周りだけ元画像に近づける |
| 色数まとめ | 色数・まとめ度合い | k-means で主要色を抽出し、ベタ塗りに寄せる |
| 仕上げ | シャープ・太さ / コントラスト / 明るさ / 彩度 | 補正後の見た目を調整（重い補正はやり直さないので即時反映） |
| 部分ブラシ | 戻す / 滑らかに | なぞった所だけ補正前に戻す、または補正をかける。「全体を補正前に」から始めれば一部だけ滑らかにできる |

長辺 2400px を超える画像は縮小して処理します。

### 画像別のコツ

- **ポスター・イラスト調**：おすすめ設定のままで十分。もっと均一にしたいときは色数まとめを 12〜16 色で。
- **描き込みの多い絵（水彩・背景美術など）**：強さ 20〜40、くり返し 1 回の軽めに。強くかけると細部が溶けます。ヒゲや瞳など細い所は部分ブラシの「戻す」で残せます。

## ファイル構成

```
index.html        ビルド済みの1枚もの（これを開けば動く）
build.py          src/ から index.html を生成
src/core.js       画像処理の本体（Web Worker 内で実行）
src/template.html 画面（HTML / CSS / UI の JavaScript）
src/sample.webp   起動時に読み込むサンプル画像
```

`src/` を編集したら `python3 build.py` で `index.html` を作り直してください。

### 処理の流れ（src/core.js）

1. 粒ノイズ除去（3×3 メディアン、任意）
2. RGB 各チャンネルにセルフガイデッドフィルタ（半径と ε を「強さ」から決定、指定回数くり返し）
3. 色数まとめ（k-means++ で主要色を抽出、境界は 3×3 で軽くアンチエイリアス、任意）
4. 輪郭保護（Sobel 勾配が強い所ほど 1. の結果に戻す）
5. 仕上げ（アンシャープマスク、彩度・コントラスト・明るさ）

1〜4 の結果はキャッシュするので、仕上げの項目を動かしたときは 5 だけを再計算します。
ノイズ量は Immerkær 法（エッジを除いた平坦部のみ）、マダラ量はボックス平均の差分（バンドパス）の中央値で推定しています。
